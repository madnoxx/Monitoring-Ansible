В проекте показано развертывание и настройка системы мониторинга с использованием средств автоматизации Ansible, включая установку, конфигурацию и запуск Node Exporter, Prometheus и Grafana для сбора, хранения и визуализации метрик сервера.

Node Exporter собирает системные метрики (CPU, память, диски, сеть) с сервера, Prometheus хранит и обрабатывает эти метрики, а Grafana визуализирует их в виде дашбордов для удобного мониторинга состояния системы.

Запуск с помощью команды ansible-playbook -i inventory.ini site.yml.
